## PC 管家三件:定性 / 打印 / 系统快照与启动项 / 自动备份 / 复审

> 来源:分家前 AGENT.md「7.10 PC 管家三件:打印 / 系统快照与启动项 / 自动备份(2026-08-31 落地;用户拍板「123」三件一批)」L503–L508。

- **定性(过筛记录)**:源起 = 用户问「PC 还有什么需要 larkwing 解决?电脑管家?」→ **不做「电脑管家」品类**(工具箱思维违 §3 零新概念),吸收其真痛点:慢了/满了/该打印/该备份 = 一句话说给 BT。**明确不做(别再提)**:杀毒/弹窗拦截(Defender 够用 + 流氓软件对抗是军备竞赛,§9 不做风控同族)· 驱动管理(装错蓝屏不可逆)· 注册表清理/内存加速球(安慰剂功能,违「如实」价值观)· 孩子上网管控(对抗性技术,违陪伴定位)。**二线缓做(真实但坑多)**:软件装卸(winget 官方源路,需确认闸 + 国内软件覆盖验证)· 网络诊断(诊断了往往修不了)。
- **打印 `print_file`**(轻办公家族第八员;paths ≤10 / copies ≤20 / 单 PDF 可 pages / 总页次 ≤100,超了**如实退回不静默钳**):一期只收 **PDF + 图片**,**按内容认格式**(%PDF 魔数 / image 格式嗅探,假后缀照认——0.2.27 教训);Office 文档如实退回指路「先转成 PDF」(docx 无干净本地转换组件,不赌第三方应用)。**Windows = 自绘 GDI 路**:pdfium 按 2480px(≈A4 300dpi)逐页栅格化 → `StartDoc/StretchDIBits` 等比 96% 居中、宽图自动横放、**透明合白底**(不合成会打出黑块);**绝不走 ShellExecute "print" 动词**(赌装了什么软件/弹 UI/无成败反馈,违 §3.5);列打印机 = 注册表 `Print\Printers` 子键、默认打印机 = `Windows\Device` 值(免 EnumPrinters 的 unsafe buffer 舞蹈)。Mac dev = `lp`(CUPS)。**pdfium 单例纪律升级**:绑定取用口收口为 `pdf::with_pdfium`(pdf_to_png 与 print_file 共用;**别处再开第二个 OnceLock = 二次 bind 必炸 AlreadyInitialized**)。不过确认闸(家庭信任圈内、后果轻,send_file 同级);送进打印队列即返回。
- **系统快照 `system_status` + 启动项 `startup_list`/`startup_toggle`**:「电脑卡 / 开机慢」的手脚;出厂技能「电脑清理」升级为**「电脑清理与提速」**(slug 不变升级刷内容)。`system_status` 只读聚合(fs_usage 姊妹):CPU 两次采样(隔 600ms)+ TOP10 进程**按名字聚合**(浏览器一家几十个进程)、百分比 ÷ 核数 = 全机口径对齐任务管理器;内存;**各卷容量/剩余**(fs_usage 只管目录树,「C 盘还剩多少」的卷级手脚在这);开机时长。依赖 +`sysinfo 0.33`(被 MSRV 1.77.2 钉,只开 system+disk 两 feature,净增 2 crate)。`startup_*` = **与任务管理器同一套机制**:启停走 `Explorer\StartupApproved\{Run,StartupFolder}` 标志位(首 DWORD 偶=启用奇=禁用;程序本体一字节不动、与任务管理器互相可见、天然可逆;Larkwing 卸载钩子操作的正是这键族);列四源(HKCU/HKLM Run + 用户/公共启动文件夹),**toggle 只改当前用户两类**(HKLM 要管理员,如实指路任务管理器);**计划任务一期不碰**(枚举输出本地化 + PS 慢,收窄自方案的「只列不禁」,真机覆盖不够再议);「**用户点名才动、绝不批量禁**」纪律进技能。依赖 +`winreg`(Win-only target dep)。非 Windows 两工具如实退回(§4.9 mac 是开发机)。记档:用 startup_toggle 禁 Larkwing 自己的自启会与设置页开关状态漂移(Run 值还在、approved=disabled),**刻意不写具名特判**(§4.11),真机撞上再议。
- **自动备份**(§6.2 一键备份/恢复的第三块;§4.11 用户拍板四数 2026-08-31:**每周 / 保留 10 份 / 默认关 / 机器清理绝不经 LLM**):`autobackup.rs` **水位线**(家庭日记同款哲学——桌面程序没有「定点活着」的假设,cron 必错过、水位线开机即补;**独立轻循环不走 jobs/scheduler、不经模型** = §5 物种③纯机制;boot 延迟 3min 首查、之后 10min 一查)。开关语义 = `backup.auto.dir` 非空即开、清空即关(**默认关不违强默认**:备到数据盘自身是假安全,目标必须另一块盘/目录,只有用户知道备到哪,没法开箱即开);设置·系统一行,选完目录**立即出第一份**(`auto_backup_now`,别让用户等下个节拍)。**轮转 = 机器清理**(拍板理由:轮转必须 100% 发生,不能建立在「模型记得删」的概率行为上;删文件代码面越窄越好):`prune_backups` 只认自家命名 `larkwing-backup-<时间戳>.zip`、按**文件名**时间戳排序(不按 mtime——拷贝会污染)、**先备后删**留 10 份、**改名 = 钉住永不删**(白捡的特性)、直接删不进回收站(程序删自己的产物、且前面还有整排还原点;fs_trash 的回收站是给「模型动用户文件」的可逆保障)。**按份数不按天数**:天数保留在低频备份下会把旧备份删光,份数则任何频率下永远有整排还原点。失败纪律(§3.5 两头):单次失败 warn 静候下轮;**超期 ≥14 天且本次也失败**才 toast 一次(3 天频控在 core;`AppEvent::Backup` tagged 增量 §6.8);设置页常显上次成功时刻/失败原因。常量单源 `autobackup.rs`(KEEP=10 / INTERVAL=7d / 查 10min / NAG=14d·频控 3d)。
- **公共接线**:新工具四件套 ×4 + delegate 五件套显式判定(system_status/startup_list 进子回合保留集;**startup_toggle/print_file 归 ④ 现场交互排除**——物理出纸/「点名才动」的对话语境);companion.json 白名单已 grep 核过(torrent 教训)。eval 守卫 3 条:`print-recent-file`(**夹具内容故意不是图片**——eval 机连着真打印机也绝不真出纸)/ `slow-pc-diagnose`(「电脑卡」先摸底)/ `startup-no-mass-disable`(未点名不许禁)。**Mac 全绿 750(新增 11 测)/ clippy 触点零警 / vue-tsc / i18n 镜像 815=815 / 预览验过设置卡 zh+en**;Windows GDI/winreg 代码 mac 编不到(cfg(windows)),**首编 + 全部真机验收见 PLAN「2026-08-31 PC 管家三件」节**。
