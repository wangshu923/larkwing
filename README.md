# Larkwing · 旺财

> 面向普通人和家庭的桌面 AI 助手。开窗就能聊,说话就能唤,关了再开它还记得你。

它默认叫 **BT**(你可以随时给它改名,喊它就用这个名字)。不同于开发者向、强调自由配置的同类,Larkwing **强默认、开箱即用**:你面对的只是一个助手,没有 agent、插件、prompt、模式这些概念——想让它干什么,说就行了。

目标平台 **Windows**(macOS 可开发运行)。安装包在 [Releases](../../releases) 下载,装好后填一个 DeepSeek API key(唯一必需的设置)就能用。

## 它能干什么

### 聊天,而且记得住

- 流式对话,答得快;你说过的喜好、家里的事,它记在「小本本」上,跨会话、跨重启都在(回忆页可看可改可删)。
- 聊偏了能回头:在你说的某句话上「从这里重新说」,或「从这里另起新会话」保留原对话换个方向。
- 想知道它刚才怎么想的,点开那段话上方的「想了想」——按时间顺序排着:想了什么、做了什么、又想了什么;跑长活时也能中途点开看到哪一步了。
- 聊天记录全文搜索;长文有专门的大编辑框,粘贴大段文字自动折成小票不刷屏。

### 说话就行

- **免手唤醒**:喊它的名字就应(改名 = 换喊法),应一声就能连续对话,不用反复喊;说「没事了」就安静退下。
- 听得准:中文识别可选「更准」档(小孩、口音友好);答话用自然人声,还能**克隆一把你喜欢的嗓子**——录进去的参考音会自动降噪、校准响度,录得不合适当场告诉你该怎么改。
- **声纹认人**:录三句话,它就知道现在说话的是谁,记忆各归各人;拿不准时宁可不认,绝不错认。
- 回声消除:它自己在放歌、说话时喊它,照样听得见你(耳机出声自动关、外放自动开,不用手动切)。

### 大活也扛得住

- **多步骤的活先列计划**:整理一整个文件夹、给几百首歌配词这类大活,它把步骤列成清单,干完一批划掉一项接着干,全部干完才收工——不用你在旁边催「继续」;计划进度在任务区和悬浮窗都看得见。
- **分头办事**:要翻很多文件、查很多网页才弄得清的事,它派帮手独立去跑,只把结果要点带回来(聊天里不会刷满几十条原始结果);互不依赖的几路还能同时跑。
- **后台长活看得见、叫得停**:跑得久的自动转后台,随口问「到哪了」它就答,说「停下」或点任务条上的停止钮就停(手上那一件做完就收手,不撕一半);跑完自己回来汇报,没成的点名报给你。十分钟没动静的它自己掐掉,并告诉你卡在哪。

### 它会的活儿,看得见也教得会

- 左边栏有一页**技能**:出厂自带十几套做法——放歌、整理文件、BT 下载、音视频加工、定时播报、存歌进曲库、报听写、睡前故事、电脑清理、盯网页变化、规划旅行……每条能看用过几次、最近哪天用的;哪条不合适,停用就好。
- **教它一套做法**:聊天里把流程说清楚,加一句「以后就这么办」,它就记成自己的手册,下回照着办;记完会复述一遍跟你确认。

### 看片、听歌

- 「放个电影」「来点儿歌」:本地硬盘、NAS、B 站都能放;记住每部片看到哪,下次接着看。
- 动画片、番剧自动连播下一集(也能说「跳到第 12 集」);歌单整夹连播,循环、随机、单曲循环嘴上说了算;双语片能切国语/原声音轨。
- **能原样放的就原样放**:先问这台电脑能解什么码,解得动的一律不重新编码;真放不了的格式(HEVC、mkv、AC3 音轨……)才自动转,能用显卡加速。播放前自己核一遍时间轴,音画对不上就换稳妥办法,不把不同步的画面播出来。
- 片子自带的字幕、旁边的 `.srt`/`.ass` 都能显示(播放条上 CC 按钮,或直接说「开中文字幕」);本地歌旁边有 `.lrc` 就逐句滚歌词。
- 拖进度条时,光标停哪儿就显示那一刻的时间(本地片还带画面缩略图),看准了再松手。

### 下载

- **网络歌曲存进电脑**:有无损拿无损(.flac),文件名和标签是干净的「歌手 - 歌名」,顺带配好歌词(.lrc);查不到词的冷门歌、儿歌,它能**听着音频**把时间轴对上去。存量老歌也能批量补词,绝不动你的音频原件。
- **磁力链 / 种子、FTP、迅雷专用链、需要账号的网盘直链(WebDAV)**都能下;大文件自动转后台——随口问「到哪了」、说「停下」就停,跑完自动回来汇报。
- **压缩包能解能打**:zip / rar / 7z 按内容认格式(不看后缀),带密码的先问你要;解压永远落进新文件夹、不覆盖任何东西。要发一批文件,先打个包再发手机。
- 下载默认进系统「下载」文件夹,下完的片和歌直接就能放。

### 文件小助手

- 「把下载文件夹的电影整理一下」「这堆歌按歌手归类」:批量移动、改名、建文件夹、删到回收站,**每一步可撤销**,同名永不覆盖。
- 读得懂文档:PDF、Word、Excel、PPT 发给它就能总结、问答;PDF 能转成图片;图里的二维码能认,也能把链接、WiFi 生成二维码**亮在对话里**让手机扫。找到的照片、转出的单据页,也直接亮出来给你过目。
- 文件带着时间:列文件显示改动日期,照片能批量读出拍摄时间——「把这堆照片按年月归档」是一句话的事。
- 「**C 盘怎么满了?**」整棵盘算占用,报最占地方的文件夹和最大的文件,一层层往下钻;要清理只动你点头的,删了也能从回收站找回。
- **能碰的文件夹**:只有你允许过的文件夹它才能读写——下载和桌面出厂就能看能存(改/删要先问),别的地方首次要动会弹卡问你,「一直允许」记住、「仅这次」只放行这回。设置里随时看和管。

### 网页上办事

- 查资料:搜索直接带回正文证据,长文章能一段段读完;时刻表、价格表这类表格不会被拍扁。
- **在网页里办事**:它开一个小窗真渲染页面(你在屏幕右下角看得见它在点什么),能点按钮、填表单、选下拉、传文件、翻页;要登录、要验证码这一步交还给你在小窗里手动完成,它接着往下办。
- 登录之后才看得到的长文能整篇通读;当前页面可原样存成 PDF。
- 要花钱、要发布、要删东西的操作,先弹卡问你才动手。

### 提醒和惦记

- 「明晚八点提醒我」「每周三提醒倒垃圾」,到点它开口;「提醒爸爸明天体检」——跨人提醒直接落到对方手机上。
- 「明天要是下雨提醒我带伞」:盯着天气(可查未来一周),条件满足才叫你;「这个页面降价了告诉我」也能盯。
- 你忙别的时,它会在悬浮窗轻轻惦记一句没看完的剧、没办完的事;夜里不打扰。

### 手机上也找得到它

- **微信、Telegram、钉钉**都能连:发文字、图片、语音、文档给它,和在电脑前一样;家里人各自扫码,各聊各的。
- 「把这个文件发我手机」「把这条链接发给妈妈」——电脑和手机之间传文件、传话,一句话的事。
- 手机上让它干的活(下载、提醒),结果也推回手机。

### 一家人用

- 家人页加上家里人,微信/钉钉的对话指认给 TA、或靠声纹认出 TA——TA 说的「我喜欢」「提醒我」就记在 TA 名下。
- 出厂性格中性,想要暖萌、贫嘴、高冷,设置里一句话改;界面有科幻、暖萌等多套皮肤,每人记住自己的。

### 放心用

- 网页上要花钱、要发布、要删东西的操作,先弹卡问你;文件夹要授权才能碰;每次确认都留痕(足迹页可查)。
- 文件操作可撤销、删除走回收站;数据全在一个本地文件夹里,一键备份/恢复/搬家(换盘)。
- 密码、API key 存系统密钥串,绝不经过对话、不进聊天记录。

## 技术一瞥

| 层 | 选型 |
| --- | --- |
| 壳 | **Tauri v2**(Rust + WebView,不用 Electron) |
| 核心 | **Rust**(`tokio`,单 crate `larkwing-core`) |
| 前端 | **Vue 3 + TypeScript**(MVVM) |
| 存储 | **SQLite** 单文件(备份 = 拷文件) |
| LLM | **DeepSeek 优先**(流式、前缀缓存);多供应商 trait 化,Gemini / OpenAI / Anthropic / Ollama 均可接 |
| 语音 | **sherpa-onnx**(识别 / 唤醒 / 声纹 / 降噪)+ msedge-tts / ZipVoice 克隆音色 |
| 影音 | yt-dlp 解析 + ffmpeg 按需转码 + localhost 中继 + 手写 MSE 自适应播放(组件用时下载,安装包不含) |
| 网页操作 | app 自己的 WebView 真渲染 + 文本编号快照(不引 headless 浏览器) |

设计上的几条硬原则:

- **人格中立底座** —— 名字、性格、皮肤全是数据,换一套数据 = 另一个助手,引擎零改动。
- **通用回合循环** —— 没有意图分类器、没有 per-task 流程;工具是**正交原语**(近 60 个),该干什么由模型自己组合。加能力 = 加一个工具文件或一份数据,循环永不改。
- **core 不产用户文案** —— 文案全在前端字典,i18n 中英同步;引擎只过 key 和数据。
- **不静默失败** —— 出错、被截断、没办成,一律如实说给你和它听,不假装成功。

## 开发

```bash
pnpm install
pnpm tauri dev        # 桌面 App(首次编译 Rust 稍久)
pnpm dev              # 仅前端(Vite @ :1420,纯视觉迭代)
cargo test --workspace   # Rust 核心 + 集成测试
pnpm build            # vue-tsc 类型检查 + 前端构建
```

- 前置:Rust(≥ 1.77.2)、Node + pnpm、Tauri v2 系统依赖(Windows 见 [docs/BUILD-WINDOWS.md](docs/BUILD-WINDOWS.md))。
- 出包:`pnpm tauri build`(不能跨平台;Windows 包走 GitHub Actions [`release.yml`](.github/workflows/release.yml) 或在 Windows 机上编)。
- 代码地图:前端 `src/`(views / components / composables)、引擎 `larkwing-core/src/`(engine / llm / store / tools / voice / media / channels)、壳 `src-tauri/`。
- **开发规范见 [AGENT.md](AGENT.md)**(动手前先读它:锁定决策、平台陷阱、各域约定都在里面);版本发布流程见 AGENT.md §7.6 与 [CHANGELOG.md](CHANGELOG.md)。
